# Orisun

> A place where I write what I think.

Orisun is my personal corner of the internet—a collection of thoughts, reflections, lessons, questions, and ideas as they come.

Some posts are about software, building products, and technology. Others are about life, creativity, observations, or advice worth sharing. There isn't a strict theme here—just things I think are worth writing down.

**Live:** https://orisunn.vercel.app

## What you'll find

- Personal reflections
- Essays and opinions
- Lessons I've learned
- Notes on software and technology
- Advice and observations
- Thoughts in progress

## Why "Orisun"?

**Orisun** is a Yoruba word meaning **origin**, **source**, or **beginning**.

The name reflects what this site is—a place where ideas begin, evolve, and are documented.

## Tech Stack

- **Framework:** Next.js
- **Styling:** SCSS Modules
- **Animations:** Framer Motion
- **UI & Interaction:** dnd-kit
- **Language:** Javascript

## Running locally

```bash
git clone https://github.com/AKOI2000/orisun.git

cd orisun
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
